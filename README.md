# Overseas Highway Hospitality

Premium responsive website for Overseas Highway Hospitality.

## Included
- Luxury-style landing page with mobile navigation
- Hotel Management, Culinary Arts and Restaurant Operations information
- Career pathways, admissions steps and FAQs
- WhatsApp enquiry form (opens WhatsApp with user-provided details)
- SEO description, accessible navigation and responsive layout

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
In repository **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then Save. After publication, the expected Pages address is `https://overseashighway.github.io/hospitality/` (only if Pages is enabled successfully).
